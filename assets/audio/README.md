# Фоновая музыка

Порядок 11 треков задан в `playlist.json`. MP3 скопированы без перекодирования.
`build.py` встраивает их в автономный `index.html`; `--web` выносит в отдельные файлы.
После окончания последнего трека список начинается сначала. Музыка запускается после
нажатия начала игры, приостанавливается на паузе и отключается общей кнопкой звука.
Боевые эффекты синтезируются отдельно.
